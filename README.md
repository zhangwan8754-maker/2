# 考研日课

自用的考研复习记录工具，手机上用。只有三个功能：

- **今日任务**：写下今天要学的内容，学完打勾。没完成的任务第二天自动留在列表里。输入框下方会列出最近两周学过的内容，点一下就加进今天。
- **学习计时**：点任务右边的三角开始计时，再点一次暂停。时长记在这条任务上。
- **日历**：按月查看每天学了多久，点某一天看当天学了什么。

## 使用

整个应用就是 `index.html` 一个页面，没有依赖，不需要构建。

- 部署：把仓库开启 GitHub Pages（Settings → Pages → 选择分支和根目录），用手机浏览器打开网址。
- 安装：在浏览器菜单里选“添加到主屏幕”，之后像普通 app 一样打开，离线也能用。

## 数据

记录只保存在手机浏览器本地，不上传。换手机或清理浏览器数据之前，在“日历”页底部点“备份与恢复数据”，把备份文本复制出来保存。
